Devices

The Daikin units this plugin controls. Units found by the automatic network scan appear below — add one manually if it lives on another subnet.

Matter

Units published over Matter work like their HomeKit accessories, and the Apple Home app (iOS 27+) also shows their electricity use in its Energy view. Rooms, scenes and automations cannot be carried over, so move units in two steps: while migrating, each unit is in the Home app twice — the HomeKit accessory keeps working while you set up the Matter one.

Language for the default names of the switches and sensors this plugin creates in HomeKit (e.g. Outdoor Temperature, Vertical Swing) — HomeKit does not translate them itself. Follows the Homebridge UI language until you pick one here. Names changed in the Home app are never touched.
Debug mode
Print debugging information to the Homebridge log.
