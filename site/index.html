Your Daikin,
in Apple Home.

A Homebridge plugin that puts your Daikin air conditioners in the Home app, over HomeKit or Matter. It talks to each unit directly on your home network, with no cloud in between.

Install in Homebridge View on GitHub

Free and open source. Needs Homebridge 2.4 or later.

Straight to the unit, on your network

The plugin controls each unit through the local interface of its Wi-Fi adapter. No Daikin account is needed, and your air conditioners keep responding when the internet is down.

What you get in the Home app

Each unit shows up as one air conditioner, with the controls it actually has.

  • Power, mode and temperature

    Only the modes your unit supports. Cool-only models whose adapter still reports heating can hide Heat and Auto.

  • Fan speed

    Automatic, quiet and five levels, the same steps as the remote.

  • Swing

    A swing toggle on the tile. Optional switches control up-and-down and side-to-side swing separately.

  • Humidity and outdoor temperature

    Extra sensors, on units that report those readings.

  • Siri, scenes and automations

    Units work like any other Home accessory, so you can ask Siri or cool the bedroom before you get home.

  • Names in your language

    Switches and sensors the plugin adds are named in any of 28 languages. Names you change in the Home app are kept.

Matter, with your electricity use Beta

Any unit can also be added over Matter. The Home app (iOS 27 or later) reads energy only from Matter accessories, so units whose adapter measures power show up in its Energy view, with live power and a running total.

The total is built from the unit's own daily and monthly history and kept in Homebridge, so it never goes backwards.

Move an existing setup in three steps

Rooms, scenes and automations can't be carried over from HomeKit, so the old and new accessories run side by side while you set things up.

  1. Start the migration

    Choose Start migration for all units in the plugin settings and restart Homebridge. Each unit now appears twice, and the HomeKit one keeps working.

  2. Pair the Matter bridge

    Add it in the Home app with the code shown in the settings, give each unit its room and rebuild your scenes and automations.

  3. Finish the migration

    Choose Finish migration and restart. The HomeKit copies are removed.

Changed your mind? Back to HomeKit moves every unit back in one step, at any point.

Works with Daikin's local-control adapters

The plugin detects which protocol each unit speaks. You only enter its IP address, or pick it from the network scan.

Newer Wi-Fi adapters
Adapters and built-in Wi-Fi modules with firmware 2.8.0 or later.
BRP069-era adapters
The interface the Home Assistant Daikin integration also uses, including built-in Wi-Fi units of the same era.
AirBase (BRP15B61)
Common on Australian ducted systems. Zone control is not available yet.
Secure BRP072C adapters
Such as the US BRP072C42. Enter the 13-digit key printed on the adapter's sticker.

Not supported: cloud-only units

Daikin's newest adapters can't be controlled over the local network at all, including the European BRP069C4x/C8x and the built-in Wi-Fi of the US ATMOSPHERA (FTXM-W). They work only through Daikin's cloud, so no local plugin can control them. An ESP32-Faikin board or an IR blaster are the alternatives. Read the full investigation

Set it up in a few minutes

  1. Install the plugin

    In the Homebridge UI, open Plugins, search for Daikin Local Platform and install it.

  2. Add your units

    Open the plugin settings. The network scan lists the Daikin units it finds, and one click adds each one.

  3. Connect to Apple Home

    Choose HomeKit or Matter, restart Homebridge and add the bridge in the Home app with the code it shows.

Requires Homebridge 2.4 or later and Node.js 22 or later. Homebridge 1.x setups can stay on plugin version 1.5.1. Full configuration reference
